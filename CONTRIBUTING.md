# Contributing to Keeply

Thank you for helping improve Keeply.

## Setup

Follow [`docs/self-host.md`](docs/self-host.md) to install dependencies, configure environment variables, and run the app locally.

## Before you open a PR

- Run `pnpm verify` (typecheck, lint, tests, and production build). It must pass.
- Prefer small, focused pull requests with a clear purpose.
- Add or update tests when you change behavior; write tests before implementation when fixing a bug or adding a feature.
- Use conventional-ish commit messages (e.g. `fix:`, `feat:`, `chore:`, `docs:`) with a short subject line.
